# Requirements

| Requirement | V5 contract |
|---|---|
| Node.js | 24.5.0 or newer |
| Homebridge | 2.0 or newer |
| Account | Dedicated secondary eufy account |
| Access | Relevant home and devices shared to that account |

Node 24.5.0 is a hard engine requirement. Older Node releases and historical crypto workarounds are
not supported by V5. See [Node.js compatibility](/troubleshooting/node-compatibility) for background.
