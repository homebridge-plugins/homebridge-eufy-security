# V4 streaming settings

::: danger Legacy V4 only
V5 camera media is not yet available. V4 presets and advanced video settings have no V5 equivalent.
:::

V4 supported P2P or RTSP sources, FFmpeg transcoding, stream presets, separate camera processes,
snapshot settings, talkback, and HKSV-specific switches. It also documented CPU, firewall, source
quality, and Node/OpenSSL compatibility considerations.

V5 will document media only after its separate video/audio input, HomeKit negotiation, RTCP, snapshot,
talkback, and HKSV contracts are implemented. See [V5 camera status](/features/cameras).
