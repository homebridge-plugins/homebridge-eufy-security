# V4 troubleshooting

::: danger Legacy V4 only
The V4 plugin/library split, per-camera filenames, reset buttons, and debug toggles do not describe V5.
:::

The former wiki asked users to reproduce an issue, enable detailed logging, download several plugin,
library, FFmpeg, and config-UI logs, then disable logging again. It also exposed reset/clear controls.

The durable lesson remains: isolate one reproducible failure and redact sensitive data. Follow the
current [diagnostics guidance](/troubleshooting/collecting-diagnostics) for the combined V5 JSONL log.
