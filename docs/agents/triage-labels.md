# Triage labels

The engineering skills use these canonical triage roles.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Waiting for reporter information |
| `ready-for-agent` | `ready-for-agent` | Fully specified for AFK work |
| `ready-for-human` | `ready-for-human` | Requires human implementation or access |
| `wontfix` | `wontfix` | Will not be actioned |

Use the tracker label in the second column whenever a skill names the canonical role.
